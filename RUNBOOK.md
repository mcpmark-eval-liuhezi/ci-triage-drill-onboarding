# Triage Drill Runbook

This sandbox repository is the practice ground for the onboarding workshop.

## Drill legs

1. **CI leg** — manually dispatch the "Triage Drill" workflow, watch the run finish, and inspect its usage metrics and artifacts.
2. **Issue-triage leg** — triage the flaky checkout e2e backlog via the parent issue and its sub-issues.
3. **Review leg** — open a small pull request and leave a review on it.

Nothing here touches a real project; it is safe to experiment freely.
